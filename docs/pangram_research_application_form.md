# Pangram research inquiry: field-by-field draft

Checked 2026-09-25 against [Pangram's research inquiry](https://www.pangram.com/contact-us/research) and the three-step form code served with that page. The desktop browser was unavailable, so the second and third steps were verified from the live page's JavaScript, **not** by submitting or clicking through the form. Recheck labels before submission. The [public GitHub repository](https://github.com/Clark-Bott/european-parliamentary-ai-study) was independently verified as public. No form was submitted.

## Step 1 — contact

- **Academic/professional email (required):** Enter your real academic or professional address. Do not enter a project placeholder.
- **Full Name (required):** Enter your real name.
- **Organization (required):** Enter your actual institution or organization. If unaffiliated, accurately describe your status rather than claiming an affiliation.
- **Website/LinkedIn (optional):** `https://github.com/Clark-Bott/european-parliamentary-ai-study`

## Step 2 — research

- **Briefly describe your project (required):** Paste or adapt these bullets. Confirm the noncommercial/academic description only if it is true for your project.

  - We are preparing a reproducible study of AI-classified parliamentary speech in Germany, France, the Netherlands, Italy, Spain, and Poland, covering 2018–2026. It extends *The Economist*'s Pangram-based analysis beyond English; it is not an exact replication.
  - Official-language corpora are locally built for five countries; Poland is still being acquired. Integrity checks, historical-control sampling, a cached Pangram API client, and analysis code are in place. Human source checks and final coverage review remain; no Pangram inference or empirical AI-prevalence results exist yet.
  - We plan to report AI-generated and AI-assisted word shares separately by country and time, using pre-2022 language-specific controls. Detector output will not be presented as proof that an individual politician used AI.
  - The five locally built corpora alone would use an estimated **2,573,331 started 100-word units** at Pangram 4 public list pricing, before Poland. We seek credits for a balanced six-language pilot and would like to discuss a larger allocation or negotiated terms for the complete study. Please advise whether the grant's three-month period can start after validation and processing approvals, or be extended.
  - Before submitting parliamentary text, we must finish source-boundary QA, close the German source gap, and review source reuse and API retention, deletion, data-processing, and EU–US transfer terms. Public code, methods, and honest status: **https://github.com/Clark-Bott/european-parliamentary-ai-study**. Raw transcripts are not in Git.

- **Will this be published/submitted for publication? (required yes/no):** Choose **Yes** if you genuinely plan to submit or publish, even if your date is provisional; otherwise choose **No**. The current form defaults to Yes, so check the selection.
- **When do you expect to publish? (required text even if the answer above is No):** Use a real target if you have one, for example `Provisional target: [quarter and year], contingent on corpus validation, rights approval, and Pangram access.` If there is no schedule, enter `No committed publication date; timing depends on data validation, processing approval, and access.` Do not invent a date.

## Step 3 — follow-up

- **Would you like to book a demo? (required yes/no):** Choose according to your preference. The form currently defaults to Yes; select No if you do not want a demo. A discussion of credits and processing terms can also be requested in the project description.
- **Submit:** Do not submit until you have checked the personal details, funding request, publication intent, and terms in your own name. Submitting this inquiry does **not** authorize API processing of parliamentary text.

The form has **no separate fields** for requested credits, budget, methodology, or a repository URL. Those details belong in the description above. Pangram's [research page](https://www.pangram.com/contact-us/research) currently advertises 200,000 credits with three-month expiry (unless extended); the five-country estimate is larger.
